-> CONSTRAINTS
   rules for data in the table

   NOT NULL     columns cannot have a null value
   UNIQUE       all values in common are different
   DEFAULT       sets the default value of a columns
   CHECK         it can limit the values allowes in a column

   ex: CONSTRAINT age_check CHECK (age>=18 and city="Delhi");

   --> KEY CONSTRAINTS


   PRIMARY KEY

    -- makes a column unique and not null but used only for makes

    create table temp(id int not null, PRIMARY KEY (id));  


    FOREIGN KEY

    --prevent actions that would destory links between tables

     create table temp (cust_id int, foreign key(cust_id) references customer (id))


     What are KEYS?

     keys are special columns in the table

     primary key

     --its a column (or set of columns) in a table that uniquely identifies each row. (a unique id)
     there is only 1 PK & it should be NOT null.

     foreign key

     --a FK is a column (or set of columns) in a table that refers to the primary key
      FKS can have duplicate and null values

      there can be multiple FKs.


      Where Clause

      to define some conditions

      select col1, col2 from table_name
      where conditions;

      OPERATORS _ Where

      Arithmetic
        --  +, -, *, /, %
      Comparison
        -- =, !=, >,>=, <, <=
      Logical
        -- AND, OR, NOT, IN, BETWEEN, ALL , LIKE, ANY
      Bitwise
        -- & (bitwise and), | (bitwise OR) 


      *** Frequently used OPERATORS

      AND         to check for both conditions to be true

      OR          to check for one of the conditions to be true

      BETWEEN     select for a given range

      IN          matches any value in the list

      NOT         to negate the given condition


      limit Clause
      sets an upper limit on number of (tuples) rows to be returned

      SELECT col1, col2 FROM tb_name
      LIMIT number;



      order by Clause

      to sort in ascending or descending order    (ASC || DESC)

      ex: SELECT * from table_name ORDER BY colname ASC;


      AGGREGATE FUNCTIONS

      perform a calculation on a set of values and return a single value.

      >COUNT()
      >MAX()
      >MIN()
      >SUM()
      >AVG()


      EDX: SELECT MAX(marks) FROM  student;


      Group by Clause

      groups rows the have the same value into summary rows
      it collects data from multiple records and groups the result by one or more column.

      SELECT col1,col2
      FROM table_name
      GROUP BY col_name(s);

      *Generally we use group by with some aggregation function


      HAving Clause

      similar to where i.e. applies some conditions on rows.
      But it used when we want to apply any condition after grouping.

      SELECT col1, col2
      FROM table_name
      GROUP BY col_name(S)
      HAVING condition

      ** WHERE is for the table, HAVING is for Group
      ** Grouping is necessary for HAVING

EX:  Select age, max(followers)
     FROM user
     Group by age
     having max(followers)>200;
