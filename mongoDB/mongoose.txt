Mongoose

A library that creates a connection between mongoDb & node.js js runtime Env

it is ODM (Object Data Modeling) library

npm install mongoose


SCHEMA

Schema defines the shape of the documents within that collection

example:

const userSchema = new mongoose.Schema({
    name:String,
    email: String,
    age: Number
});

 NOTE:  Mongoose uses Operation Buffering

 Mongoose lets you start using models immediately, without waiting for mongoose to establish a connection to mongoDB.
